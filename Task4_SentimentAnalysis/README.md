# Task 4 - Sentiment Analysis

## Objective
Analyze text data and classify it as Positive, Negative, or Neutral using Natural Language Processing (NLP).

## Tools & Technologies
- Python
- Pandas
- NLTK
- VADER Sentiment Analyzer

## Features
- Analyze text reviews
- Classify sentiment as Positive, Negative, or Neutral
- Generate sentiment scores
- Save results to a CSV file

## Output
The analysis results are saved in `sentiment_results.csv`.
