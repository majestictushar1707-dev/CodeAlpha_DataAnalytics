# Task 1 - Web Scraping

## Objective
Scrape book information from the Books to Scrape website and save the extracted data into a CSV file.

## Website
https://books.toscrape.com/

## Technologies Used
- Python
- Requests
- BeautifulSoup4
- Pandas

## Features
- Connects to the website
- Extracts book titles
- Extracts book prices
- Saves data into a CSV file
- Displays the first few records in the terminal

## Files
- scraper.py → Python script for web scraping
- books.csv → Scraped data
- requirements.txt → Required Python libraries

## How to Run

1. Install dependencies

```
py -m pip install -r requirements.txt
```

2. Run the script

```
py scraper.py
```

## Output

The script generates:

- books.csv
