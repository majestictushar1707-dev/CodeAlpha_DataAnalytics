# Titanic Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python. The objective is to understand the dataset, identify patterns, detect missing values, and visualize important insights using graphs.

## Dataset
- Dataset: Titanic Dataset
- Total Records: 891
- Total Columns: 12

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Dataset Loading
- Dataset Information
- Missing Value Analysis
- Statistical Summary
- Survival Count Visualization
- Survival by Gender Analysis
- Age Distribution
- Passenger Class Distribution
- Fare Distribution
- Correlation Heatmap

## Key Insights
- The dataset contains 891 passenger records.
- Age, Cabin, and Embarked contain missing values.
- Female passengers had a significantly higher survival rate than male passengers.
- Most passengers belonged to Passenger Class 3.
- Most passengers were between 20 and 40 years old.
- Ticket fares were highly uneven.
- Passenger class had a noticeable relationship with survival.
